# Use Astryx Butter as the Nischit design-system foundation

**Status: accepted.** Nischit will use Astryx components and theme tokens, extending the Butter theme into a Nischit theme. Butter matches the requested approachable, bright, warm visual direction while its React/StyleX token system supports tenant-safe customization, SSR builds, and a consistent component vocabulary. The 60–30–10 rule will guide color proportion: warm light foundations, supporting surfaces, and restrained blue/action accents.
